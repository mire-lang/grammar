# Mire TextMate grammar

TextMate grammar for the Mire programming language (`.mire`), used by GitHub
Linguist and compatible editors.

The grammar follows Mire's current syntax: `load`/`load!`, `use`/`use!`,
namespaced calls, nested functions, typed values, attributes, interpolation,
closures, pattern matching, FFI declarations, and both line and block comments.

This repository is intentionally independent from the compiler. It contains no
compiler implementation and is distributed under the MIT license.
